GitHub Pages · $0 · auto progress

Maintain this site

UX lives in HTML/CSS/JS. Coverage numbers are generated into docs/data/progress.json from the repo — never type them by hand.

Regenerate progress (required)

  1. After changing locale-packs/, playbooks/, or field-notes/:
  2. Run python3 scripts/generate_site_data.py
  3. Run python3 scripts/validate.py
  4. Commit the updated docs/data/progress.json

On main, GitHub Action sync-site-data.yml also refreshes and pushes progress.json automatically.

Edit look & explore UX

  1. docs/index.html — sections / structure
  2. docs/styles.css — visual design
  3. docs/app.js — how JSON becomes UI
  4. Preview: open docs/index.html via a local static server if fetch is blocked

Tip: python3 -m http.server 8080 --directory docs then open http://localhost:8080 (file:// may block fetch).

Agent / contributor rules

See AGENTS.md and .cursor/rules/site-progress.mdc. Agents must regenerate progress.json when coverage sources change.

Pages enable (once)

  1. Repo Settings → Pages
  2. Branch main · folder /docs
