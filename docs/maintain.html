Maintain this site

The website is static files in docs/. Edit HTML/CSS in the repo, push to main, Pages updates automatically once enabled.

Enable once (GitHub UI)

  1. Open Repo → Settings → Pages
  2. Under Build and deployment, set Source to Deploy from a branch
  3. Branch: main · folder: /docs · Save
  4. Site URL will be https://anshul9t6.github.io/DeployerX/

Edit content

  1. Change copy in docs/index.html
  2. Change look in docs/styles.css
  3. Preview locally: open docs/index.html in a browser
  4. Commit + push — Pages rebuilds in ~1 minute

Keep deep docs in the GitHub repo (playbooks, locale packs). This site is the front door only — less to maintain.

What you do not need

No Vercel/Netlify bill, no custom domain required, no Node build for v1. GitHub Pro is optional for this — public Pages works on free plans too.
