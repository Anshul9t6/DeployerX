# docs/ — GitHub Pages site

Public site root for **DeployerX** (static HTML/CSS, $0).

## Enable

1. GitHub → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/docs`

URL: https://anshul9t6.github.io/DeployerX/
