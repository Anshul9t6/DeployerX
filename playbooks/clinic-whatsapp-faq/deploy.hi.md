## Path A — बिना पैसे (आज)

1. मंज़ूर FAQ सेव करें (`faq.txt` या Sheet CSV: `question,answer`) — पंक्ति शामिल करें: **बॉट मेडिकल सलाह नहीं देता**।
2. पेस्ट-रेडी प्रॉम्प्ट बनाएँ:

   ```bash
   python3 -m decision.prompt clinic-whatsapp-faq --faq faq.csv --locale in/rajasthan/jaipur --lang hi --out prompt.txt
   ```

   भाषा: `hi`, `en`, `pt`। टर्मिनल नहीं है? `prompts/system.<lang>.md` में `<<<FAQ>>>` बदल दें।
3. ब्राउज़र में ChatGPT या Claude खोलें। `prompt.txt` को निर्देशों में पेस्ट करें।
4. मरीज़ का मैसेज पेस्ट करें → पढ़ें → WhatsApp **आप** भेजें।
5. कठिन सवाल FAQ शीट में जोड़ें।
6. स्टाफ को [`operator-card.hi.md`](operator-card.hi.md) दें — एक पेज, पाँच नियम।

## Path B — कम बजट (बाद में)
