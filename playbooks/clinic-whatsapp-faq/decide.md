# Decide — Clinic WhatsApp FAQ

## Use when

- Same questions repeat: hours, address, appointment process, fasting for tests, report timing
- Staff already answers on WhatsApp
- Owner wants fewer missed messages without hiring an engineer

## Do NOT use when

- The bot would diagnose, prescribe, or interpret reports
- Emergency / triage is expected via chat
- Prices and packages change constantly with no written list
- Owner will not review answers for the first week
